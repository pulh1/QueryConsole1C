# Общий вызов и функции языка запросов 8.3.24 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перенести обычные вызовы в единый AST и семантический каталог,
поддержав 20 существующих и 28 недостающих имён функций.

**Architecture:** Грамматика строит `ВызовФункции` с именем и контейнером
аргументов. Общий каталог определяет арность, ограничения, результат и
категорию; посетители обходят аргументы напрямую. Восемь специальных форм
сохраняют отдельный синтаксис. Общая библиотека parsergen не меняется.

**Tech Stack:** русский BSL, EDT-MCP, Serena, YAxUnit, Python parsergen/pytest.

**Spec:** [2026-10-27-generic-query-function-calls-design.md](../specs/2026-10-27-generic-query-function-calls-design.md), принята пользователем 2026-10-27.

**Состояние 27.10.2026:** реализация Tasks 2–5 и автоматические проверки
выполнены; три P2-замечания независимого ревью исправлены и проверены RED→GREEN.
Финальный прогон: Python 761 passed / 1 skipped; YAxUnit 571 passed / 3 skipped.
Runtime-сверка на 8.3.24 и UI-проверка
недоступны в текущем окружении. Фактические результаты, исключённые SQL-пробы
и оставшиеся ограничения перечислены в [матрице](../matrices/2026-10-27-query-function-coverage.md).

## Global Constraints

- Совместимость: 1С 8.3.24; `lookahead = 2`; текущие entrypoints сохраняются.
- 48 общих имён и 8 специальных форм — перечни из спецификации.
- `Аргументы` общего вызова всегда являются `СписокВыражений`, в том числе пустым.
- Неизвестное имя и неправильная арность — семантические ошибки; разделители — синтаксические.
- Метаданные и BSL сначала читаются через EDT; запись BSL точечная, с revision guard.
- Старые parser/lexer/factory sidecars в `yaxunit` остаются историческим oracle.
- Фикс `НЕДЕЛЯ` уже выполнен; его регрессия сохраняется при смене AST.
- Нет пользовательских функций, нового общего модуля, полной двуязычности,
  `ГРУППИРУЮЩИМ НАБОРАМ` или отдельного механизма вычисления функций.
- Работа выполняется в текущей feature-ветке, привязанной к живому EDT-проекту.
- Пользователь согласовал выполнение; промежуточные задачи не требуют нового согласования.

## Review Focus

1. Нулевой вызов и несколько аргументов не повреждают стек типов/результатов — Tasks 2, 5.
2. Поле с именем функции и `СТРОКА` как тип не превращаются в вызов — Task 3.
3. Контекст ВТ/группировки не протекает во вложенный запрос — Task 4.
4. Генерация до семантики сохраняет неизвестное имя и `НЕДЕЛЯ` — Tasks 2, 3, 5.
5. Составной/неизвестный тип и `NULL` не теряют полиморфность — Tasks 1, 2, 5.
