# Исправление двух дефектов независимого ревью

**Цель:** закрыть два P2 из ревью диапазона `382ed96..b780adb`.
**Основание:** пользователь поручил исправить оба дефекта после отчёта ревью.
**Контракт:** сохраняем утверждённую модель из [плана реестра](2026-10-27-query-functions-review-fixes.md).

## Решение

В приватном методе контекста `ПостроительМоделиЗапроса` добавляем текущие
`ЗапросВыбора`, `ОператорЗапроса` и начальную `РольВыражения`.
Роль при обработке раздела устанавливает существующий семантический код.
Базовый контекст отдельного выражения остаётся минимальным, публичные интерфейсы сохраняются.

В `СодержитВызовПредставления` прекращаем поиск при встрече `ЗапросВыбора`.
Вложенный запрос проходит собственный семантический анализ;
запрет непосредственного использования результата ПРЕДСТАВЛЕНИЕ сохраняется.
