# СГРУППИРОВАНОПО на 8.3.27 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Согласовать семантику СГРУППИРОВАНОПО с фактическим исполнением.

**Architecture:** Признак зависимости аргумента от записей в существующем
стеке вызовов; точное сравнение зависимого аргумента с ключами оператора.

**Tech Stack:** Русский BSL, EDT-MCP, Serena, YAxUnit, COM 8.3.27.2170.

**Spec:** [Согласованный scope и решение](../specs/2026-11-04-groupedby-semantics-design.md).

## Ограничения и фокус ревью

- BASE `bc42f70`; текущий EDT checkout feature/functioms_gramar_refacoring.
- Пользователь согласовал выполнение плана и runtime 8.3.27; повторного
  согласования тех же действий не требуется. Исполнение — в текущей сессии.
- Изменяются посетитель, генератор текста запроса, один тестовый модуль,
  документы и отчёты. Генератор добавлен после воспроизведения связанного
  дефекта пустой группировки в round-trip тесте.
- BSL — только минимальные guarded-записи EDT с актуальным hash.
- Никаких подмен контекста, повторного сканирования AST и обходов на исключении.
- Проверить вложенные вызовы, повторное поле, КОЛИЧЕСТВО(*), исходный NULL,
  независимость посетителей и границу вложенного запроса.
- Один итоговый коммит после проверок и независимого read-only ревью.
  Merge/push не выполнять.
