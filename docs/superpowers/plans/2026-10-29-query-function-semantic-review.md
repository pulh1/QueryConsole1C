> for execution after explicit user approval. Steps use checkbox syntax.

**Goal:** Учесть все замечания пользовательского ревью и сохранить проверки
контекстных функций без временной подмены общего контекста.

**Architecture:** Разреженное соответствие ограничений типов; отдельные
неизменяемые правила применения функций, передаваемые в анализ явно;

**Tech Stack:** Русский BSL, 1С 8.3.24, EDT-MCP, Serena, YAxUnit.

**Spec:** [Проект решения](../specs/2026-10-29-query-function-semantic-review-design.md).

Ограничения runtime/UI и оставшиеся диагностики перечислены в итогах ниже.

  плана. Перед реализацией снять актуальный baseline.
- Совместимость 8.3.24; EDT запуск ранее использовал 8.3.27.2170.
- НовоеОписаниеФункцииЗапроса() без аргументов; заполнение именованными helpers.
- Реестр через ПовтИсп; арность массивом чисел, тип результата/Агрегатная без
  смены прежнего контракта.
- Из метаданных менять только имена двух новых модулей реестра и ссылки
  на них. Грамматику, AST, generated parser, исторические sidecar-модули
  и ПоставщикИсполняемыхПредставлений не изменять.
- Не запускать прежние спорные UUID/GROUPING SQL-пробы.
- BSL: актуальное чтение EDT → guarded-запись → перечитывание → diagnostics delta.
- Сохранять предметные обработчики ошибок, не связанные с подменой контекста.
- ОбработатьВыражение сохраняет первые три аргумента, четвёртый теперь —
  обязательные правила вместо неиспользуемого параметра готового посетителя.
  Во всех остальных helpers новые обязательные аргументы ставятся перед
  существующими необязательными; все активные callers мигрируют явно.
- Всё выполнение этого плана — один итоговый коммит после тестов и ревью.
  Промежуточные коммиты этапов, merge и push не выполнять.

## Основные риски и их проверки

1. Конструктор или параметр ВТ случайно проходит как самостоятельное выражение:
   проверки редактирования, отборов СКД, параметров ВТ, итогов и сортировки.
2. Номер аргумента перепутан с индексом массива:
   первая/вторая позиция, свободная первая и ограниченная вторая.
3. После исключения состояние одного посетителя попадает в другой анализ:
   отдельный новый экземпляр на каждое выражение, включая вложенный запрос.
4. Вложенный запрос наследует внешнюю функцию или разрешение АвтоНомера:
   положительные и отрицательные случаи через границу запроса.
5. Нулевой/необязательный аргумент, NULL, составной тип меняют поведение:
   каталог 48 функций, арности 0/1/2/3/6, тесты типов и вывода параметров.
