## Согласованный контракт

1. Каталог переносится в `КОНС_РеестрФункцийЯзыкаЗапросов`; обращения идут
   через `КОНС_РеестрФункцийЯзыкаЗапросовПовтИсп` с повторным использованием.
2. `НовоеОписаниеФункцииЗапроса()` без аргументов создаёт начальную структуру;
   каждая ветка поиска вызывает свой именованный метод заполнения.
3. `ДопустимыеКоличестваАргументов` заполняются числовыми значениями сразу.
4. `ТипыАргументов` — массив позиций, каждая позиция содержит массив допустимых
   типов. Пустой массив позиции означает любой тип; `Ссылка` и `Неопределено`
   являются отдельными альтернативами. Набор для СТРОКА перечисляется явно.
5. `КоличествоАргументовДляВыводаТипа`: 0 — фиксированный результат,
   1 — первый аргумент, 2 — объединение первых двух. `ВозвращаемыйТип` хранит
   ОписаниеТипов либо Неопределено. Специальное преобразование ссылочных типов
   и обработка NULL остаются в семантике.
6. Остаётся булев признак `Агрегатная`. Категория и ОграничениеАргументов
   удаляются; контекст и дополнительные ограничения проверяются по имени.
7. ЗапросВыбора, ОператорЗапроса и РольВыражения создаются в контексте запроса.
   КореньВыражения хранится в семантическом посетителе. Базовый контекст
   отдельного выражения этих полей не содержит, в том числе после обхода.
