# Query Lexer Unit Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Закрыть характеристическими YAxUnit-тестами публичный контракт `Обработки.ЛексическийАнализатор` и исправить подтверждённую ошибку завершения `ПолучитьТекстЗапроса` на EOF.

**Architecture:** Тесты находятся в одном серверном общем модуле `КОНС_Обр_ЛексическийАнализатор_МО` проекта `yaxunit` и создают реальные экземпляры лексера через существующую непривилегированную фабрику. Варианты входов перечисляются явно в регистрации YAxUnit; производственные таблицы лексера не используются для генерации ожиданий. Единственное изменение QueryConsoleZUP — условие выхода из цикла `ПолучитьТекстЗапроса`.

**Tech Stack:** 1С:Предприятие 8.3.24, EDT 2026.1, русский BSL, YAxUnit 25.12, EDT-MCP.

## Global Constraints

- Метаданные и BSL изменяются через EDT-MCP с `contentHash`/`expectedHash`; ручная запись `.mdo` запрещена.
- Проект тестов: `yaxunit`; тестируемый проект: `QueryConsoleZUP`.
- Конфигурация запуска: `QueryConsoleZUP Тонкий клиент`; фильтр расширения: `YAXUNIT`.
- Все локальные тестовые объекты имеют префикс `КОНС_`.
- Общие тестовые модули серверные, непривилегированные и не используют транзакции.
- Тесты вызывают только публичные методы `Инициализировать`, `УстановитьОбрабатываемыйТекст`, `СледующийТокен`, `ТипыТокенов` и `ПолучитьТекстЗапроса`.
- Входы и ожидания перечисляются явно и не вычисляются из `КлючевыеСлова`, `Лексемы` или других приватных таблиц производственного лексера.
- EOF остаётся пустым токеном с `Тип = Неопределено`; менять этот контракт нельзя.
- Разрешённая производственная правка ограничена заменой проверки `Токен = Неопределено` на `Токен.Тип = Неопределено` внутри `ПолучитьТекстЗапроса`.
- Каждый пакет проходит RED, точечный GREEN и повторный прогон всего модуля.
- Тесты не читают и не записывают данные информационной базы.

### Task 5: Комментарии, ошибки и восстановление текста

**Files:**

- [ ] **Step 1: Проверить комментарии**

Добавить сценарии:

```text
"// комментарий" + ПС + "Поле"              -> первый значимый токен `Поле`, строка 2

"Первое // комментарий в конце"              -> после `Первое` EOF-токен

```

Комментарии не должны возвращаться отдельными токенами.

- [ ] **Step 2: Проверить ошибки**

Использовать реальный объект и fluent assertion `ЮТест.ОжидаетЧто(Лексер).Метод("СледующийТокен").ВыбрасываетИсключение(...)`:

```text
Символ(34) + "незакрытая"   -> "Ожидается закрывающая кавычка"
"#"                         -> "Не удалось разобрать запрос"
```

Для `"// комментарий без перевода строки"` ожидать EOF без исключения.

Добавить тесты `ПолучитьТекстЗапроса` для:
