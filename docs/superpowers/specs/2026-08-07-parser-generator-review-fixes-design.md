# Исправления по review миграции генератора парсера

## Цель

Устранить подтверждённые замечания PR №70, не смешивая миграцию генератора с изменением грамматики или production-парсера.

## Объём изменений

- Команда `analyze` преобразует превышение лимита материализации lookahead в контролируемую ошибку без traceback.
- Явное `--lookahead 0` без конфигурационного файла отклоняется общей проверкой диапазона.
- Генератор BSL добавляет fallback-исключение, если actionful epsilon-альтернатива не выбрана по SELECT; только полностью пустая альтернатива остаётся неявным epsilon-fallback.
- Из `resolver._diagnostic` удаляется неиспользуемый параметр с неразрешённой аннотацией `RelatedLocation`.
- Описание установки и повтор слова в docstring исправляются точечно.

## Отложенные замечания

- Два замечания к `query-language.grammar` не исправляются: грамматика должна остаться побайтно равной источнику миграции, а её функциональные изменения относятся к следующей ветке.
- LLK201 не изменяется: проверка повторной декларации продукции подтвердила совпадение порядковых номеров из `enumerate` и `Alternative.index + 1`.

## Проверка

Для каждого функционального дефекта сначала добавляется тест, воспроизводящий текущее неверное поведение. После минимальных исправлений выполняются затронутые тестовые модули, полный Python-набор, `parsergen validate` и `parsergen generate --check`. Production-каталог парсера остаётся неизменным.
