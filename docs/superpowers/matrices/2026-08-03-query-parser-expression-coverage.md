# Матрица покрытия парсера выражений

Дата сверки: 2026-08-04. Базовый commit: `0656e35`.

Матрица построена по живой модели EDT: `QueryConsoleZUP/DataProcessors/Парсер/ObjectModule.bsl`
содержит ровно 55 функций от `НеТерминалВыражение` до
`НеТерминалОпциональноеПродолжениеАргументаЗначение`. Публичная точка наблюдения —
`Обработка.Парсер.РазобратьВыражение`; приватные продукции тестами не вызываются.

Статусы:

- `GREEN` — указанный зарегистрированный тест прошёл и проверяет приведённый публичный путь AST;
- `GREEN, транзит` — ветка следует из однозначной цепочки вызовов live source для входа,
  а тест проверяет публичный результат; инструментальное line coverage не снималось;
- `Частично` — покрыта только перечисленная альтернатива, рядом явно указан пробел;
- `Opt-in RED` — отдельный исполнимый acceptance-тест воспроизводит известный дефект;
- `Пробел` — зарегистрированного доказательства нет;
- `Вне entry point` — продукция входит в expression-scope файла, но вызывается только из
  полного разбора запроса, не из `РазобратьВыражение`.

1. Альтернатива подзапроса у `ОперандВ` и три продукции `*МоделиЗапроса` относятся к

   `Таблица.(...)`, simple CASE и CASE без `ИНАЧЕ`.

   `ТочностьЧисла` без явной числовой точности.

   перечислены в отдельной acceptance-матрице.
