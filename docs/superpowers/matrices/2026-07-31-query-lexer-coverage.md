# Матрица покрытия лексического анализатора запросов

Проверяемый контракт: публичные методы обработки
`ЛексическийАнализатор`. Основной набор находится в общем модуле
`КОНС_Обр_ЛексическийАнализатор_МО` расширения `yaxunit`.

| Категория | Входы | Тестовый метод | Статус | Примечание |
| --- | --- | --- | --- | --- |
| Ключевые слова | 82 явно зарегистрированных значения | `КлючевоеСловоКлассифицируется` | Покрыто | Проверяются класс, тип и исходная лексема |
| Регистр ключевых слов | `вЫбРать` | `КлючевоеСловоНеЗависитОтРегистраИСохраняетЛексему` | Покрыто | Тип нормализуется, лексема сохраняется |
| Служебное имя типа | `ID_СРешеткой` | `СлужебноеИмяТипаНеЯвляетсяКлючевымСловом` | Покрыто | Фиксируется текущее поведение: обычный `ID` |
| Односимвольные лексемы | `. / { } < % = & > ( ) * + , - ;` | `ЛексемаКлассифицируется` | Покрыто | Каждый вариант зарегистрирован явно |
| Двухсимвольные лексемы | `<= <> >=` | `ЛексемаКлассифицируется` | Покрыто | Проверяется единый токен |
| Обычные идентификаторы | `Поле`, `field_1`, `Поле123_Другое` | `ИдентификаторКлассифицируется` | Покрыто | Тип `ID`, исходный регистр сохраняется |
| Временные идентификаторы | `#ВТ`, `#temp_1` | `ИдентификаторКлассифицируется` | Покрыто | Тип `ID_СРешеткой` |
| Числовые константы | `0`, `42`, `12.5`, `.5`, `1.`, `01` | `ЧисловаяКонстантаСохраняетЗначение` | Покрыто | Проверяются класс, тип, лексема и значение |
| Строковые константы | пустая, обычная, с экранированной кавычкой, многострочная | `СтроковаяКонстантаСохраняетЗначение` | Покрыто | Проверяется декодированное значение |
| EOF | пустой текст | `ПустойТекстВозвращаетПустойТокен` | Покрыто | Поля `Тип`, `Класс`, `Лексема` равны `Неопределено` |
| Пробелы и табуляция | без отступа, два пробела, табуляция | `ПозицияТокенаОпределяется` | Покрыто | Проверяются номер строки и символа |
| Переводы строк | `ПС`, `ВК + ПС` | `ПозицияТокенаОпределяется` | Покрыто | Второй токен начинается со строки 2 |
| Координаты временных идентификаторов | `#ВТ`, `#temp_1` | `КоординатаВременногоИдентификатораСоответствуетТекущемуПоведению` | Покрыто | Характеристические значения 4 и 8 |
| Повторное использование | `Первое`, затем `Второе` | `ЛексерПовторноИспользуетсяСНовымТекстом` | Покрыто | Позиция сбрасывается публичным методом установки текста |
| Комментарии | в начале, между токенами, в конце, несколько строк | `КомментарииНеВозвращаютсяКакТокены` | Покрыто | Комментарии не образуют токенов |
| Комментарий до EOF | комментарий без перевода строки | `КомментарийБезПереводаСтрокиЗавершаетсяEOF` | Покрыто | Возвращается EOF без исключения |
| Неизвестный символ | `@` | `НекорректныйВводВызываетИсключение` | Покрыто | Ожидается ошибка разбора |
| Незакрытая строка | открывающая кавычка и текст | `НекорректныйВводВызываетИсключение` | Покрыто | Ожидается закрывающая кавычка |
| Незавершённый временный идентификатор | `#` | `НекорректныйВводВызываетИсключение` | Покрыто | Ожидается ошибка разбора |
| Восстановление текста | константа, квалифицированное поле, параметр, комментарий | `ТекстЗапросаВосстанавливаетЗначимыеКонструкции` | Покрыто | Пробелы форматировщика не фиксируются |
| Завершение восстановления | `ВЫБРАТЬ 1` | `ВосстановлениеТекстаЗавершаетсяНаКонцеВхода` | Покрыто | Регрессия проверки EOF |

Последний пакетный прогон модуля: 141 тест-кейс, 141 пройден,
ошибок и пропусков нет.
