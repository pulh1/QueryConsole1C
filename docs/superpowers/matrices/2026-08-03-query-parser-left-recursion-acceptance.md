# Acceptance-матрица будущей грамматики выражений

Дата проверки: 2026-08-04. Базовый commit: `0656e35`.

Производственный `Обработка.Парсер` генерируется из грамматики и в рамках текущего
expression-плана не исправляется вручную. Исполнимые RED изолированы в модуле
`КОНС_Обр_ПарсерБудущаяГрамматика_МО` и регистрируются только при явном module-фильтре.

## Фактические opt-in RED

| Вход | Текущий результат | Желаемый контракт | Тест | Статус |
|---|---|---|---|---|
| `--1` | Error: `Значение не является значением объектного типа (Знаки)` в `НеТерминалУнарнаяОперацияПродолжение`, строка production-модуля 2324 | `УнарнаяОперация`; `Знаки=["-", "-"]`; `Выражение.Тип="Константа"`; `Выражение.Значение=1` | `ПовторныеУнарныеЗнакиРазбираются` | Зарегистрирован opt-in; ожидаемый `Errors=1` |
| `НЕДЕЛЯ(&Дата)` | Узел и аргумент строятся, но `ИмяФункции="ДЕНЬМЕСЯЦА"`; assertion получает `ДЕНЬМЕСЯЦА` вместо `НЕДЕЛЯ` | `Тип="ФункцияЧастьПериодаЧислом"`; аргумент `&Дата`; `ИмяФункции="НЕДЕЛЯ"` | `НеделяСохраняетИмяФункции` | Зарегистрирован opt-in; ожидаемый `Failed=1` |
| `1 +` | `{(1, 3)}: Синтаксическая ошибка. Неожиданный токен "+"` | исключение содержит `Синтаксическая ошибка. Ожидается следующий токен` | `НезавершеннаяБинарнаяОперацияСообщаетОбОжидаемомТокене` | Зарегистрирован opt-in; ожидаемый `Failed=1` |

Свежий явный запуск future-модуля с `updateScope="extension:yaxunit"` воспроизвёл ровно
эти три результата: `Total=3`, `Passed=0`, `Failed=2`, `Errors=1`, `Skipped=0`.

## Сценарии левой рекурсии и глубины

Следующие строки пока не являются YAxUnit-тестами и не считаются выполненными. Они должны
быть зарегистрированы только в отдельной задаче изменения грамматики/генератора, сначала
как RED, затем переведены в GREEN после регенерации production-парсера.

| Вход | Желаемая группировка/результат | Статус |
|---|---|---|
| `10 - 3 - 2` | `(10 - 3) - 2` | Не зарегистрировано: ожидает изменение грамматики |
| `100 / 10 / 2` | `(100 / 10) / 2` | Не зарегистрировано: ожидает изменение грамматики |
| `1 + 2 + 3 + 4` | `((1 + 2) + 3) + 4` | Не зарегистрировано: ожидает изменение грамматики |
| `А=1 И Б=1 И В=1` | `(А=1 И Б=1) И В=1` | Не зарегистрировано: ожидает изменение грамматики |
| `А=1 ИЛИ Б=1 ИЛИ В=1` | `(А=1 ИЛИ Б=1) ИЛИ В=1` | Не зарегистрировано: ожидает изменение грамматики |
| 1000 слагаемых | разбор завершается без переполнения стека | Не зарегистрировано: ожидает изменение грамматики |

## Критерий перевода в основной набор

После изменения грамматики и регенерации:

1. явный future-модуль должен стать GREEN без ослабления assertions;
2. сценарии ассоциативности проверяют публичную левую форму AST, а не номера продукций;
3. стресс-тест проверяет завершение и корректный результат, не внутреннюю реализацию;
4. только после этого подтверждённые acceptance-тесты переносятся в основной модуль.
